# CratePilot original interface artwork

The application mark, play, pause, stop, copy, and window-control glyphs in `UI/Theme/PixelArtwork.xaml` are original vector artwork created for CratePilot. They use filled integer-coordinate geometry and are embedded as compiled WPF resources. No third-party icon pack, game mark, social-network logo, or downloaded artwork is included.

`UI/Theme/ClassicTheme.xaml` contains the original classic desktop theme: square beveled controls, a wine/purple-to-dark-blue title gradient, subtle pastel surfaces, and original pixel glyphs. The style is inspired by classic desktop interfaces, not copied branding or screen content.

The interface uses Tahoma and Consolas supplied by Windows, with system fallback. No font file is redistributed. No runtime asset download, browser, live blur, external style package, or network request is required.
